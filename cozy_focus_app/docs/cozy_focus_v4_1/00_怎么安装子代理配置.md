## 3. 主模型

新开一个干净 Codex Goal。

Claude Sonnet 4.6

## 4. Gemini writer

Codex 会按 `.codex/agents/gemini_implementer.toml`
spawn `gemini_implementer`。

当前 model ID：
`11/gemini-3.8-flash-high`

如果你的选择器显示不同 ID，只改该 TOML 的 model 一行。

## 5. 为什么 concurrent threads = 1

这里故意只允许一个 spawned child。

避免：
- 两个写手同时改相同 Dart 文件
- Claude/Gemini 重复审计
- 多子线程堆积 context
- 互相等待与返工循环
