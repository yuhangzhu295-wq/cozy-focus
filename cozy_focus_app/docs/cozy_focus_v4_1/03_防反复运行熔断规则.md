# 03 防反复运行熔断规则

## Gemini 首次实现
第 10 次 read-only 调用前必须开始真实 edit。
否则 BLOCKED_NO_EDIT + STOP。

## Gemini Review Fix
第 6 次 read-only 调用前必须开始真实 repair edit。
否则 BLOCKED_FIX_NO_EDIT + STOP。

## Claude Pre-review
最多 12 次只读。
到上限必须 PLAN 或 BLOCKED。

## Claude Diff Review
最多 10 次只读。
不允许重新审整个项目。

## 同一轮重复限制
无代码变化时：
- 同一 source file 最多读 2 次
- 同一图片最多打开 1 次
- 同一目录最多 list 1 次
- git status 最多 1 次
- git diff --stat 最多 1 次

## 图片
只选：
designs/pages/
或
designs/pages_ascii/

默认 ASCII。
禁止两套都读。

## context compaction
只从 CURRENT_STAGE.json 恢复。
禁止重新开始 Audit。

## repair rounds
最多 2。

## 一个 Goal 一个 Stage
APPROVED/BLOCKED 立刻 STOP。
