# 01 — 16 页视觉对照矩阵

对照方式：设计包 `01_FINAL_16_DESIGNS/` 的 16 张单页设计图 vs 真机截图（模拟器 1080×2400 @ 420dpi = **411×914 dp**，对应任务书的 412×915 目标）。

设计图是**展板**（中间手机模型 + 四周说明），所以比较的是展板中间的手机内容；`outputs/visual_qa/reference/` 同时存了展板原图与自动裁切的屏幕区（裁切脚本试了六种判据，只有约一半可靠，因此**以展板为准**，裁切图仅作参考）。

数据说明：设备上的数据全部通过真实 UI 创建（任务、计划、专注记录），未使用设计稿示例数据。**限制**：`adb input text` 无法输入中文，因此任务标题用 ASCII；App 自身文案仍为中文，不影响布局与层级对照。

## 全局：主色绿与设计图不符（影响全部 16 页）

对照 05 时量到设计图实心按钮 `#446E4B`、实机 `#5E8D6D`，于是扫了全部 16 张展板：

| token | 设计图命中像素 | 判定 |
|---|---|---|
| `primarySage` 旧值 `#5E8D6D` | **1,468**（抗锯齿边缘，不是填充） | **错**，已改为 `#44714B`（命中 125,256，每张展板都有） |
| `primaryLight #EAF2EB` | 162,685 | 对 |
| `primaryDark #4A7256` | 35,771 | 对 |
| 中性色（输入框底 `#FAF8F1` vs 实机 `#FBF8F2`） | 吻合 | 展板无整体偏色 |

顺带修掉一个对比度缺陷：白字压旧绿是 3.81:1（低于 AA 4.5），新绿 5.66:1。设备复验见 `02_BEFORE_AFTER/`，主绿像素 120,297 → 121,370，其余绿像素数未变。
