# 02 审查时机与返修状态机

Claude 必须在三个时间点审查：

1. **编码前**：做范围/架构/测试施工单。
2. **Gemini 首次编码后**：只审实际 diff。
3. **每次 Gemini 修复后**：只审未关闭 findings + repair diff。

状态：

NOT_STARTED
→ CLAUDE_PLAN_READY
→ GEMINI_IMPLEMENTED
→ WAITING_CLAUDE_REVIEW

通过：
→ APPROVED_FOR_FINAL_GATE
→ APPROVED
→ STOP

不通过：
→ CHANGES_REQUIRED
→ GEMINI_FIXED
→ WAITING_CLAUDE_REVIEW

repair_round 最大 2。

→ BLOCKED
→ STOP
