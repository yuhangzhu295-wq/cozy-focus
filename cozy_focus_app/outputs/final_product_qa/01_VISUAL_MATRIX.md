# 01 — 16 页视觉对照矩阵

对照方式：设计包 `01_FINAL_16_DESIGNS/` 的 16 张单页设计图 vs 真机截图（模拟器 1080×2400 @ 420dpi = **411×914 dp**，对应任务书的 412×915 目标）。

设计图是**展板**（中间手机模型 + 四周说明），所以比较的是展板中间的手机内容；`outputs/visual_qa/reference/` 同时存了展板原图与自动裁切的屏幕区（裁切脚本试了六种判据，只有约一半可靠，因此**以展板为准**，裁切图仅作参考）。

数据说明：设备上的数据全部通过真实 UI 创建（任务、计划、专注记录），未使用设计稿示例数据。**限制**：`adb input text` 无法输入中文，因此任务标题用 ASCII；App 自身文案仍为中文，不影响布局与层级对照。

## 01 首页 — 对照结果

| 设计要素 | 实现 | 结论 |
|---|---|---|
| 问候语 + 副标题（`下午好` / `今天也辛苦了，一起专注一会儿吧。`） | 实现为 `和 咪咪 一起 / 专注吧！` + `专注当下，让更好的自己慢慢长大。` | 差异：文案不同（实现含伙伴名，是真实能力）。是否改为时段问候待定 |
| **当前任务卡片**：圆圈 + 任务名 + `专注中` + `2/3 · 预计 90 分钟` + `›` | **不存在** | **缺陷（缺失功能入口）**：首页没有"当前任务"卡片，设计图把它放在问候语正下方，是最显眼的新元素 |
| 选择专注时长 + 5/25/50/90 药丸 + `自定义 ›` | 一致（25:00 + 四个药丸 + 自定义） | PASS |
| 开始专注（实心绿 + 播放图标） | 一致 | PASS |
| 今天的专注：环形 + 时长 + `完成 N 次专注` + **按小时的柱状图**（轴 6/9/12/15/18/21） | 环形 + `0 分钟` + `连续专注 N 天`；**无柱状图** | **缺陷**：缺少设计图的按小时分布图；实现改显示连续天数（另一个指标） |
| 放松一下：设计为**一行**（小宠物图标 + 标题 + 副标题 `累了就休息一会儿吧` + `›`） | 实现为卡片内的**描边按钮**（与开始专注同宽） | 差异：层级与位置不同（设计图把它放在页面下部作为独立行） |
| 右上角入口 | 设计为叶片图标；实现为齿轮（设置）+ 一句励志小卡 | 差异：多了一张励志卡片（B3 要求删重复励志文案，待处理） |
| 顶部宠物与场景 | 设计为**实景房间照片**（窗、绿植、木桌）+ 趴着的 Mochi；实现为**平面插画**贴在纯色底上 | 差异：场景资产缺失（见 `08_RELEASE_BLOCKERS.md`）。布局层面宠物已是主视觉 |
| 底部导航 | 一致 | PASS |

| 设计要素 | 实现 | 结论 |
|---|---|---|
| 标题 `今天` + `10月8日·周三` + 右上日历图标 | 一致（实机 `10月8日·周四`，日期正确） | PASS |
| **下一个任务卡片**：图标 + `下一个任务` + 任务名 + `25 分钟 · 工作` + 实心绿 `开始` 按钮 | 一致（实机卡片含 `Write the product spec` / `25 分钟 · 工作` / 开始） | PASS |

## 04 专注模式 — 对照结果

| 设计要素 | 实现 | 结论 |
|---|---|---|
| 标题 `专注` + 返回 + 右上**全屏图标** | 有标题与返回；**无全屏图标** | 差异（缺一个入口） |
| 副标题 `和 Mochi 一起，专注当下` / `每一次投入，都在靠近更好的自己。` | 实现为一句鼓励气泡（`保持专注，咪咪 正在陪着你`）+ 顶部一句文案 | 差异：文案与位置不同 |
| 模式分段 `番茄钟 / 正计时 / 深度专注` | 一致 | PASS |
| **大圆环计时器**（环上有嫩芽图标，环内 25:00 + `专注中`） | **没有圆环**：只有大号数字（`04:57`），全页无任何环 | **缺陷（核心视觉缺失）** |
| 四个圆形控制按钮一行：`白噪音` / `暂停` / `记一下` / `完成`，标签在图标下 | 实现为：一个整宽描边按钮 `记一下` + `暂停` / `提前结束` 两个整宽按钮 | 差异：控制区布局完全不同 |
| `白噪音` 开关 + 自然/海浪/雨声/篝火/风鸣 音源 | **不存在** | 正确：仓库无音频素材，契约禁止假开关（`BLOCKED_EXTERNAL`） |
| 宠物位于环下方、房间场景中 | 宠物为平面插画，位于数字下方 | 场景资产缺失（同 01 行） |
| `记一下` 弹层：标题 + × + 输入框 + `保存` | 一致（分心收集箱，含分类标签） | PASS |
