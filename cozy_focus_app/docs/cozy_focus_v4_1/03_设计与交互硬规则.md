# 03 设计与交互硬规则

## 视觉

- 正式页面：1170×2532
- 一页一张
- 暖米色 / 低饱和绿色
- Mochi 白色软萌小狗
- 圆角卡片
- 大量留白
- 少 CTA

## 导航

Bottom Navigation 永远最多：

首页 / 记录 / 成长

设置右上角。

## 产品原则

这是养成系数字钟，不是工具箱。

用户主任务是：

开始专注。

因此禁止：

- 首页十几个快捷入口
- 多个“前往xx”按钮
- 把库存/制作/图鉴做成独立底部入口
- 奖励页连续跳转
- 多层菜单才能开始一次专注

## 数据

所有业务数字必须来自真实状态。
设计图中的数字只表示排版。
